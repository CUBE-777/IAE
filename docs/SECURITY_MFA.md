# المصادقة الثنائية (MFA) وسياسة الخصوصية — دليل التشغيل

## كيف تعمل المصادقة الثنائية هنا

- **اختيارية لكل مسؤول**: من لم يفعّلها لا يتغيّر عليه شيء.
- **مَن فعّلها** يُطلب منه رمز تطبيق المصادقة (TOTP) بعد كلمة المرور. والأهم أن **الخادم يفرضها** (migration `0024`):
  دالتا `current_admin_role()` و`is_admin()` — وعليهما تعتمد كل سياسات RLS — تُرجعان «لا صلاحية» إذا كان للحساب عامل
  موثّق وكانت الجلسة بمستوى `aal1` فقط. فلا يفيد من عرف كلمة المرور أن يستدعي الـ API مباشرة.
- الواجهة: شاشة الرمز في `/admin/login`، والتفعيل/الإيقاف من `/admin/security` (متاحة لكل الأدوار).
- دالة `admin-create-user` تستخدم `service_role` (تتجاوز RLS)، لذا تفحص بنفسها: من فعّل MFA ولم تكن جلسته `aal2` يُرفض بـ 403 ولا يستطيع إنشاء مسؤول. من لم يفعّلها لا يتغيّر عليه شيء. أعد نشر الدالة بعد هذا التحديث.

## قبل النشر (بالترتيب)

1. في Supabase: **Authentication → Sign In / Providers → Multi-Factor** وتأكد أن TOTP مفعّل (Enroll + Verify).
2. شغّل `0023_privacy_consent.sql` ثم `0024_mfa_enforcement.sql` في SQL Editor (آمنان لإعادة التشغيل).
   **0023 يجب أن يسبق نشر الواجهة** لأنها ترسل العمود `privacy_consent`.
3. انشر الواجهة (Netlify).
4. انشر الدالة: `supabase functions deploy admin-create-user --no-verify-jwt`.
   إن كان للموقع نطاق مخصص غير `fsa-iae.netlify.app` فأضفه:
   `supabase secrets set ALLOWED_ORIGINS="https://example.org,https://www.example.org"`.

## تجربة آمنة (لا تقفل نفسك)

1. ادخل بحسابك، ثم `/admin/security` → فعّل MFA وامسح الرمز بهاتفك.
2. **لا تُغلق جلستك الحالية.** افتح نافذة خاصة (Incognito) وجرّب الدخول بالبريد وكلمة المرور ثم الرمز.
3. إن نجح الدخول فأنت مطمئن. أبقِ حسابًا إداريًا آخر بلا MFA للطوارئ حتى تتأكد.

## الاسترداد إن ضاع هاتف مسؤول

Supabase Dashboard → **Authentication → Users** → المستخدم → قسم Factors → **Delete/Remove factor**.
بعدها يدخل بكلمة المرور فقط ويعيد التفعيل. (هذه العملية لا تحتاج SQL ولا تعديلًا على الكود.)

## سياسة الخصوصية

الصفحة `/privacy` (ar/fr/en من `privacy.*` في ملفات الترجمة) **قالب أولي** صيغ من ممارسات الموقع الفعلية (ما يجمعه النموذجان
وما يعرضه الموقع). على مكتب النادي مراجعته وتعديل مدة الاحتفاظ وجهة الاتصال بما يطابق الواقع قبل اعتماده، وليس استشارة قانونية.
