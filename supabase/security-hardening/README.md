# security-hardening — دليل التنفيذ

مجموعة SQL **للتنفيذ اليدوي** بعد المراجعة. لم يُنفَّذ أي شيء على قاعدة بيانات حقيقية، ولا Build ولا Deploy. لا حذف لأي جدول/عمود/سجل/ملف، ولا تغيير لأسماء الدوال أو توقيعاتها.

**ما تم التحقق منه:** شغّلت كل migrations (0001–0060) على Postgres 16 محلي، ثم طبّقت 02–06 وشغّلت `07_post_checks.sql` (A–F: نجاح كامل؛ وعلى القاعدة قبل الإصلاح يفشل الفحص A كما يُفترض). جرّبت أيضًا `08_rollback.sql` على نسخة مصلَّحة، وقارنت صلاحيات 10 أدوار قبل/بعد (متطابقة). المحاكاة تقريبية لـ Supabase، فجرّب على نسخة/staging أولًا.

## الترتيب
1. انسخ القاعدة احتياطيًا (Supabase backup / PITR).
2. `01_pre_checks.sql` — قسمًا قسمًا. **احفظ 5.4.** تأكد أن 1.0 ≥ 1 (مطوّر نشط) وأن 3.2 و5.1 فارغان.
3. `02_roles_hardening.sql` — الجزء 1-أ (حرج) ثم 1-ب. كل جزء معاملة مستقلة.
4. `03_member_media_privacy.sql`
5. `04_security_definer.sql`
6. `05_token_security.sql` — تأكيدات فقط، يُلغى في نهايته.
7. `06_rls_storage_hardening.sql`
8. `07_post_checks.sql` — يجب أن ترى `PASS A…F`. أي `FAIL:` يعني مشكلة؛ لا تتجاوزها.
9. بعد التنفيذ: اختبر يدويًا دخول المسؤول + MFA، طلب انخراط عام، رابط تفعيل، دعوة + RSVP، بطاقة QR، رفع صورة من الإدارة، معاملة ميزانية.
10. التعديلات الخارجة عن SQL: `09_app_changes_required.md`.

**الأهم إن لم تنفّذ غير شيء واحد:** `02` الجزء 1-أ (دوال الحراسة).

## التراجع
`08_rollback.sql` (الأوامر معلّقة بالتعليقات؛ أزل التعليق عن القسم المطلوب). `ROLLBACK` لا يلغي معاملة نُفّذ `COMMIT` لها. التراجع عن 1-أ يعيد الثغرة. لا مرحلة تحذف بيانات.

## ما قد يتأثر
| المرحلة | قد يلاحظه |
|---|---|
| 1-أ | لا أحد مشروع. من بلا دور إداري لم يعد يمرّ من الحراسة |
| 1-ب | `super_admin` (غير المطوّر) لا يعدّل/ينشئ/يعطّل `super_admin` من الواجهة، وتظهر له رسالة خطأ؛ لا يربط/يفكّ حساب مطوّر |
| 2 | سرد ملفات `members/` لغير الظاهرين في Storage API فقط. العرض بالروابط المباشرة كما هو |
| 3 | لا أثر |
| 5 | حذف `audit_logs` للمطوّر فقط |

## تنبيهات
- 02/1-ب يتوقف إن لم يوجد مطوّر نشط (حتى لا تُقفل إدارة `super_admin`).
- رابط صورة عام معروف يبقى يفتح (راجع `00` §6 و`09` §3).
- `07` يكتب بيانات تجريبية داخل معاملة تُلغى؛ شغّله في SQL Editor كاملًا لا سطرًا سطرًا. يتخطّى تجهيز Storage بهدوء إن لم تسمح الصلاحيات.
